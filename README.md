# CH Auto Workshop

A long-form React + Vite website for CH Auto Workshop, Sahiwal, Pakistan.

## Included
- Responsive premium workshop UI
- GSAP scroll/reveal animations
- Lightweight Three.js hero visual
- Services, About, Why Us, Workshop Gallery and Contact sections
- Direct phone CTA: 0301-6105452
- Vercel-ready configuration
- Mobile navigation and smooth scrolling

## Run locally
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```
